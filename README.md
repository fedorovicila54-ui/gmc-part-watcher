# GMC Terrain: поиск черного молдинга

Ищет молдинг переднего левого крыла GMC Terrain II (2017–2022), черный без хрома. Подходит окрашенный и неокрашенный черный. Уведомления предназначены для [@GMC12213_bot](https://t.me/GMC12213_bot).

## Что проверяется

- Kufar: публичный JSON страницы категории и описания подходящих объявлений; адаптер проверен на реальном HTML.
- AV.by: публичные карточки каталога GMC; точный фильтр категории пока не установлен. Первая страница всего бренда не гарантирует полный охват. Выдача защищена SafeLine (HTTP 468), адаптер пока проверен только на тестовых карточках.
- Bamper: узкая категория модели и детали. При проверке площадка вернула Cloudflare 403; разметка реальной выдачи не подтверждена.

Парсер уважает robots.txt, делает паузу между запросами, не решает CAPTCHA и не обходит защиту. Блокировка — ошибка источника, а не «найдено ноль». Проверяется первая страница каждого источника; на Kufar запрашивается не более 20 подходящих описаний за запуск. Это ограниченный мониторинг публичной выдачи, а не полный каталог всех площадок.

## Уведомления

`black` — в тексте явно указана черная отделка самой детали и подходящее поколение/год. `review` — подходящий кандидат, но цвет, поколение или форма требуют проверки. Цвет автомобиля-донора не доказывает цвет молдинга. «Без хрома» не доказывает черный цвет. Явный хром, другая сторона и поколение исключаются; исходное объявление 138518208 всегда исключено.

Фотографии автоматически не анализируются. Даже `black` означает подтверждение по тексту продавца: сверьте форму, крепления и совместимость. Полная накладка арки не считается точным совпадением отдельного молдинга. Номера 84107336 и 84408437 не внесены в whitelist: исходное фото недоступно, геометрия не сверена.

20 октября 2026 вручную проверены фото Kufar 1083692519, 1059660113, 1086543965, 1086430663 и 1059660114: у детали видна хромированная вставка, эти объявления добавлены в excluded_ids. Фото 1082999997 и 1086293821 показывают черные большие накладки арки; совпадение формы с исходным молдингом не подтверждено.

Новое объявление отправляется один раз для каждого статуса. Если `review` становится `black`, приходит новое уведомление. Изменение цены само по себе повтор не вызывает. Максимум 10 уведомлений об объявлениях за запуск, остальные будут отправлены позднее. О недоступном источнике сообщается один раз до смены состояния. При сбое после отправки, но до сохранения state возможен повтор — строгое exactly-once через Telegram API недостижимо.

## Подключение Telegram на GitHub

1. Нажмите **Start** у [@GMC12213_bot](https://t.me/GMC12213_bot).
2. В BotFather откройте `/mybots` → ваш бот → **API Token**. Не публикуйте токен в файлах, Issues или логах.
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
4. Ваш числовой chat ID можно узнать у @userinfobot либо локальной командой `python connect_telegram.py` после Start (токен передается через переменную окружения).
5. Откройте **Actions → GMC Part Watcher → Run workflow**. Снимите `dry_run` для реальной отправки.

Без обоих Secrets выполняется только проверка, сообщений не будет. Токен и chat ID не записываются в код, отчет или ветку состояния. Не подключайте к этому боту webhook другого приложения: локальный помощник использует getUpdates.

## Бесплатный запуск

Workflow запускается на стандартном Ubuntu runner публичного репозитория в 17 и 47 минут каждого часа (UTC; каждые 30 минут в любом часовом поясе). Это периодические задания GitHub Actions, а не сервер 24/7. Стандартные runners публичных репозиториев бесплатны: [GitHub billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions).

GitHub может задержать или пропустить запуск при нагрузке. Для публичных репозиториев расписание отключается после 60 дней без активности; [ограничения расписания](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule). Workflow должен оставаться на default branch `main`.

Состояние отправок хранится в отдельной ветке `bot-state` (только id/статус объявления, время и состояние источника; без Telegram-данных). Workflow имеет `contents: write` только для сохранения этой ветки. Одновременные запуски сериализованы. Если запись состояния в GitHub не удалась, проверьте Actions до следующего запуска: иначе возможны повторы. Недоступность части площадок отображается предупреждением, если хотя бы одна площадка прочитана. Полная недоступность или ошибка Telegram завершают job с ошибкой.

В этом репозитории секреты добавлены в GitHub Environment с именем `TELEGRAM_BOT_TOKEN`; job подключен к этому окружению. При переносе используйте такое же окружение или удалите поле `environment` и задайте repository secrets. Перед отправкой workflow проверяет через getMe, что токен принадлежит именно GMC12213_bot.

## Исходники и локальный запуск

В GitHub исходное дерево упаковано в `source.zip`: workflow распаковывает его в `app/`, устанавливает зависимости, запускает тесты и монитор. Архив содержит обычные редактируемые Python-файлы и тесты. После изменения исходников выполните `python pack.py` и загрузите новую версию `source.zip`. Конфигурация `config.json` в корне GitHub-репозитория имеет приоритет над копией внутри архива: фильтры можно менять прямо на GitHub.

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m partwatch
```

Последняя команда — dry run: создает `report.json`, ничего не отправляет и не помечает объявления отправленными.

```powershell
$env:TELEGRAM_BOT_TOKEN = Read-Host 'Токен BotFather'
python connect_telegram.py
$env:TELEGRAM_CHAT_ID = Read-Host 'Ваш chat ID'
python -m partwatch --notify
```

Exit code 0 — источники прочитаны; 2 — хотя бы один источник недоступен, рабочие источники все равно обработаны; 1 — ошибка настроек, состояния или Telegram. Сбой Telegram останавливает рассылку; неуспешная отправка не сохраняется как доставленная.

`notify_review: false` в config отключает кандидатов с неизвестным цветом. `black_oem_numbers` заполняйте только после сверки точного OEM и формы; сейчас список пуст. Отчет и журнал Actions показывают кандидатов и причины, но не содержат токенов.
